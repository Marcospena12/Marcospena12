### 🚀 O que ando construindo
- 💻 **Desenvolvimento Web & Software:** Construindo aplicações completas, interfaces reativas (Next.js, React, Tailwind) e estruturando serviços de backend orientados a dados (Node.js, TypeScript).
- 🧠 **Agentes de IA e RAG:** Criando sistemas autônomos de suporte integrando LLMs (via Groq/OpenRouter) com bancos vetoriais em PostgreSQL/PGVector.
- ⚙️ **Automação de Processos:** Orquestrando fluxos complexos, consumo de APIs, webhooks e CI/CD (GitLab/Slack) utilizando n8n.
- 🖥️ **Homelab & Infra:** Mantendo servidores on-premise com Proxmox, Synology NAS, Docker e automação predial via Home Assistant.
